Configurar RoderichEvents
Para sincronización en tiempo real entre Federico, Yeni y Rodrigo necesitás conectar Firebase (gratis). 3 pasos simples:
1
Crear proyecto Firebase
Andá a console.firebase.google.com → "Crear proyecto" → nombre: roderichevents
2
Activar Realtime Database
Menú → "Realtime Database" → "Crear base de datos" → En Reglas pegá: {"rules":{".read":true,".write":true}} y publicá
3
Pegar la config en el archivo
⚙️ → "Configuración del proyecto" → "Tus apps" → Web → copiá el objeto firebaseConfig y pegalo en FIREBASE_CONFIG al inicio del index.html
Después de editar el archivo, hacé commit y Vercel re-deployea automáticamente.
